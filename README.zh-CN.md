# 神经工坊 · Neural Atelier

[English](README.md) · **简体中文**

[![神经工坊——在 3D 桌面上搭建神经网络的解谜游戏](docs/images/social-preview.png)](https://hacking.pub/games/neural-atelier/)

一个在 3D 桌面上搭建神经网络的网页解谜游戏。拖动组件、连接端口，再试跑自己的网络：向量会沿线路移动，经过矩阵映射和其他计算，最后与目标结果比较。

**[在线试玩 →](https://hacking.pub/games/neural-atelier/)** · [本地启动](#本地启动) · [怎么玩](#怎么玩)

目前有 58 个关卡，从连接第一个向量开始，逐步加入矩阵投影、FFN、Q/K/V、RoPE、Attention、自回归，以及 CPU / GPU / ANE 调度、量化、KV 缓存等端侧推理概念。

最后的 **[运行完整的原版 Transformer](https://hacking.pub/games/neural-atelier/#transformer-demo)** 是演示关：67 个基础运算组件已经摆好、连好，直接点试跑即可。展开编码器、解码器各一层、双头注意力、四维特征、ReLU FFN、词表概率与选词；连续生成三个新词，不需要搭建。组件分层悬浮在三维空间，不再使用棋盘。拖动旋转视角，Shift / 右键拖动或开启“平移视角”后拖动来平移，滚轮以鼠标所在区域缩放。默认 0.25× 下每列计算约一秒，和普通关卡一致，不再压缩整轮时长；可暂停、调速、切换区域或双击查看组件，“跟随数据”让镜头平滑追踪当前计算，拖动、缩放或切换区域后自动交还手动控制，也可随时重新开启；组件与连线固定。每个新词会送回输入，完整文字保留在画面上，矩阵使用三词滑动演示窗口。教学权重未训练，可能重复出词。跟随支持远景、中景、近景，结束后回到模型中心。

其中 **30 关主线**先学原版 Transformer，**13 关现代扩展**再比较 SiLU、SwiGLU、RMSNorm、Pre-LN 和 RoPE，**6 关云端推理**从单机单卡入门，再练习两卡分片与通信，**9 关端侧推理**独立探索 Qwen 27B、Kapitsa 与 Apple ANE。四条路线在关卡菜单中分别选择，完成一条不会自动进入另一条。

## 工坊里有什么

从一根线、一块小矩阵开始，逐步组合投影、激活、门控和残差，接出完整的 FFN。双击模块可以打开介绍卡片，转动立体模型，查看它的计算方式。

| 向量经过矩阵映射 | 打开卡片，看看模块内部 |
| --- | --- |
| ![输入向量经过矩阵投影，变成四维输出](docs/images/matrix-projection.jpg) | ![门投影卡片，展示立体模型、矩阵、公式与计算示例](docs/images/module-card.jpg) |

<sub>以上画面与封面取自较早的中文版本实机截图。当前游戏支持中文和英文。</sub>

接线决定真实计算结果。运行时可以观察数据在网络中流动，最后再查看结果是否符合目标，自己琢磨哪里需要调整。

| 阶段 | 搭建与探索的内容 |
| --- | --- |
| **序章 · 7 关** | 传递向量、投影、ReLU、降维，搭出原版 FFN，再从组件架取用它，最后加上残差。 |
| **原版网络 · 21 关** | 词向量、正弦位置编码、LayerNorm 与 Post-LN；Q/K/V、打分、Softmax、汇合、单头与多头；四维过渡、编码器、因果注意力、交叉注意力、解码器与完整两半。学习词表分数、选词和独立的生成循环，再直接运行全部展开的模型。 |
| **组件过渡 · 2 关** | 先复用已合成的 Q/K 打分模块，后面再组装双头因果注意力。FFN 的搭建与复用已在序章 05–06 完成；复用关不会再次奖励同一个组件。 |
| **现代扩展 · 13 关** | 比较 SiLU、单支路与门控 FFN、SwiGLU、RMSNorm、Pre-LN、RoPE 和现代解码器块。 |
| **端侧推理 · 9 关** | CPU / GPU / ANE 分工、张量布局、批处理、KV 缓存、量化、融合、并行执行与前缀复用。 |

主线遵循 [Attention Is All You Need（2017）](https://arxiv.org/abs/1706.03762) 的运算顺序：ReLU FFN、相加的正弦位置编码、**先残差相加再 LayerNorm（Post-LN）**，包含编码器和解码器。基础算子用两维，完整层用**四维、两个头、各一层**，让反复归一化后仍能看清特征差异。LayerNorm 的缩放为 1、偏移为 0，FFN 偏置为 0，推理时关闭 dropout。固定权重用于教学，不是训练好的翻译模型；末尾的生成循环关另用固定转移表解释控制流程。

选关页把主线分为六个学习阶段，可快速跳到各阶段并查看完成进度。关系图区分 **10 关扩展组件、11 关准备输入、12 关组装编码器**，并明确 **13 关开始搭解码器**；编码器输出会在 15 关重新作为源句信息接入。原有编号、链接和存档保持一致。

组件架从放置教学之后逐步累积：保留已经学过、适用于当前向量或序列形式的组件，让玩家自己判断哪些有用。还没教过的组件不会提前出现。原版与现代章节共享已学组件，端侧引擎章则改用有成本模型的调度任务；组合组件的卡片会展示内部组成。已有线路、通关记录、关卡编号和链接保留。

在 **设置 → 清除全部通关记录** 中确认，可把当前浏览器的所有关卡标为未通过。保留连线、组件位置、可恢复方案和偏好设置；运行中需要先停止试跑。

从因果遮罩关起，组件架分组展示组合组件和基础组件，较早的零件保留在可展开区域；现代扩展也沿用这一布局。保留可选与干扰组件，分组不代表参考答案的连线。

新增 **实践 · 云端推理**，位于现代模型和端侧推理之间。当前可玩 6 关：上传输入、CPU 算子回退、中间结果留显存，再进入按列分片、按行分片、两卡 FFN。多机、MoE、CUDA Graph、MTP 以及固定版本的 GLM-5.3 / Kimi K3 案例见[课程规划与模型依据](docs/cloud-curriculum.md)，这些后续关卡尚未开放。

## 怎么玩

- 点圆形输出口，再点方形输入口完成接线，也可以拖拽接线。
- 点连线或已连接的输入口，再点“删除连线”；也可以按 Delete / Backspace 删除选中的线。
- 搭建关卡中，单击棋盘模块，在旁边点击“删除组件”；撤销会恢复模块及连线。
- 拖动模块调整布局；拖动场景旋转视角，滚轮缩放。所有关卡都能在“复位视角”旁开启“平移视角”后拖动，也可按住 Shift / 右键拖动；运行和暂停时同样可用，不会移动组件。
- 试跑时也能拖动台面或模块转动视角、滚轮缩放；此时模块位置和连线不会被改动。
- 从组件架拖入模块，拖动时可以看到对应的 3D 组件预览；也可选中卡片后点空位放置。“收回组件”只移除这个副本及其连线，并归还数量。
- 双击棋盘或左侧组件架中的模块，都能打开介绍卡片；库存用完的组件也能查看。键盘聚焦组件架条目后，按 Enter 同样可以查看。
- 点击“关卡”旁的“给个提示”，按需查看详细结构、本关重点和出口含义；点击 ×、弹窗外或按 Esc 关闭。
- 点击“试跑我的网络”，观察向量的流动与计算，结果会在运行后显示。
- 全部输入通过后会弹出完成提示：选择“重玩本关”会保留组件和接线，回到搭建状态，手动点击“试跑我的网络”才开始运行；也可以直接进入“下一关”。
- 在“试跑我的网络”和“暂停”旁直接调整速度，向左慢、向右快，运行时也能调节。“设置”里调整语言、背景音乐和音量；通过关卡菜单切换章节。
- 点击左上角的 N / 神经工坊标志，可以回到首页。
- 默认按照浏览器语言偏好选择中文或英文，可以手动覆盖。切换语言保留接线和关卡进度。
- 默认运行速度为 **0.25×**，手动选择的速度会被记住。
- 开场可直接点击“进入工坊”或按 Esc 跳过；音乐在用户操作后开始，切到后台会暂停。

组件架默认使用最小档，可用 **− / ＋** 调整并记住尺寸。点击“收起组件架”折叠，点击“组件架”重新展开。

**[接成一层原版编码器](https://hacking.pub/games/neural-atelier/#encoder-layer)** 用小图区分“词之间交换信息”和“FFN 分别加工每个词”。组件架把四维组件放在一起，也保留学过的干扰选项；早先的零件可展开查看和拖出。残差相加、LayerNorm 各用一个选项，可取两块，旧存档里的命名和连线仍然有效。

序章前五关提供固定组件，**所有连线都需要自己接**。序章 06 **[用上刚组好的 FFN](https://hacking.pub/games/neural-atelier/#workshop)** 从**空台面**开始，要自己拖入序章 05 合成的 ReLU FFN，再接线。序章 07 也从空台面开始，拖出同一个 FFN 和残差相加，计算 X + FFN(X)；ReLU 仍在 FFN 内部。从序章 06 起，搭建关会保留组件架。之后的原版基础解谜关从空台面开始，即使组件架只提供一种组件，也需要自己拖入、摆放并接线。现代扩展与引擎关保留各自的预设起点。旧版自动摆好但还没接线的原版起点会先存档再收回组件，可用“恢复上次方案”找回；已有连线或通关的存档继续保留。开放搭建关允许重复拿取，每类通常有两块；FFN 的线性投影有四块，合并了原来计算相同的“线性投影”和“内容投影”库存。FFN、Attention、完整层的台面上限分别为 **8、12、7** 块，组件架会显示余量。合并后已有存档保留全部组件、摆放和接线。

通关后的序章，从另一关主动选入时会开启新挑战，可以点“恢复上次方案”找回上次通关的摆放和接线，不会自动运行。刷新或使用浏览器前进 / 后退会恢复已有尝试及其完成状态；从首页或选关页回到当前关卡也不会重置棋盘。未完成的搭建仍然保存，即使这关以前通过也不会丢失。完成弹窗中的“重玩本关”保留当前棋盘，既不重置也不直接运行。原版网络、现代扩展和引擎关继续直接加载各自的存档。

在 **[自注意力](https://hacking.pub/games/neural-atelier/#self-attention)** 等组合关卡中，全部输入通过后，棋盘上的网络会聚拢成一个组件，再飞入左侧组件架，之后才显示完成弹窗。新组件保留同样的计算，可在适用的搭建关卡中拖出使用。原来的搭建仍会保存。合成动画支持暂停、跳过，并适配系统的减少动态效果偏好。

共有 **16 个合成与收录节点**，覆盖原版 FFN、两关封装教学、注意力网络、四维词向量与位置、编码器与解码器层、完整原版编码器—解码器、SiLU 与 SwiGLU FFN、带残差的 FFN，以及现代解码器层。固定的 FFN 序章通关后会展示已收录组件，支持查看说明，留待后续搭建关使用；棋盘仍保持固定。封装保留各自的端口和运算，FFN 修改量、FFN 加残差、包含归一化的序列 FFN 是不同组件。

**[词不变，特征变宽](https://hacking.pub/games/neural-atelier/#wider-features)** 用同一个 token 对照两维与四维词表。每一维是表示这个 token 的一个数值坐标，不一定对应某个能单独命名的属性。这里为教学切换词表，不是把上关输出临时升维；真实模型通常从一开始就选定词向量宽度。

FFN 的内容支路直接复用**线性投影**，卡片会说明“内容”是它的用途，并与使用另一套权重的**门投影**对照。**SwiGLU** 放在原版编码器—解码器之后的现代扩展中：先分别练权重、相乘、门控、降维，再学 RMSNorm，最后综合搭建。原有的关卡链接、接线和通关记录在调整顺序后仍然保留。

关卡和接线进度保存在当前浏览器的 `localStorage` 中，而不在 URL 里。导航链接使用不随语言变化的稳定 ID：

- `#wire` 或 `#encoder-layer` 直接打开对应关卡的工作台，原有关卡链接继续有效。
- `#home?lesson=encoder-layer` 打开首页，并保留该关为当前关卡。
- `#menu?lesson=encoder-layer&track=main&group=decoder&from=game` 打开指定路线、学习阶段的选关页。`lesson` 表示当前棋盘，不是菜单的浏览位置；`from=home` 或 `from=game` 决定关闭菜单时返回首页还是工作台。没有学习阶段的路线省略 `group`。

刷新与浏览器前进 / 后退会恢复页面、路线、学习阶段和关卡。浏览选关页不会重置接线或撤销历史，普通滚动也不新增导航记录。没有 hash 的网址会显示首页，并使用已保存的当前关卡。离开工作台或换关会停止正在运行或暂停的动画，但合成动画前已保存的通关结果仍然保留。通过历史回到另一关时加载该关最新的本地接线，不是回退到某次编辑快照。分享链接不会分享接线或通关记录。

可以拖动模块调整位置或重新搭建。矩阵投影展示加权贡献；SiLU 则让数值沿弯曲通道通过，并按照 sigmoid 门值改变大小。

移动向量使用横向小托盘，分量从左到右排列，与输入和输出托盘保持一致；整段输入则保留各 token 的独立排列。

面向桌面浏览器，需要 WebGL 2；目前不支持手机布局。

运行时可点击试跑按钮旁的 **暂停**，保留当前计算画面；仍能拖动和缩放视角，点击 **继续** 从原处接着运行。向量投影会把横向排列的分量送到对应的权重旁，用同色标记和乘加算式依次展示每个输出，所有输出保持相同节奏；快慢统一由速度设置控制。

Q/K/V 投影会对每个词使用同样的逐项动画：正在计算的权重列高亮，实际乘积送到输出球，算好的向量按词名暂存，最后一起送出。“同一份输入，三个角色”只检查出口的 V。Q/K 在本关可以不放置、不接线；它们用于后续的注意力打分，V 的生成不依赖它们。已有接线与通关标记保留。

## 本地启动

需要 Node.js 22 或更高版本。在终端克隆项目并安装开发依赖：

```sh
git clone https://github.com/chainhelen/neural-atelier.git
cd neural-atelier
npm ci
npm run dev
```

如果已经有源码，进入项目目录后执行 `npm ci` 和 `npm run dev` 即可。

打开 <http://127.0.0.1:5173/>。按 `Ctrl+C` 停止服务。依赖安装后，平时启动只需 `npm run dev`；修改代码后刷新浏览器查看效果。

只想试玩，也可以不用 Node.js，在项目目录运行：

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

请通过 HTTP 打开，直接双击 `index.html` 会受到浏览器对 ES Module 的限制。

## 项目结构

这是无需构建的纯前端项目，使用原生 HTML / CSS / JavaScript 和本地附带的 Three.js r180。运行时没有后端接口、账号服务或数据库；Node.js 只用于开发服务器和测试。

| 文件 | 内容 |
| --- | --- |
| `index.html`、`style.css` | 页面与样式 |
| `game.js` | 交互、场景、连线、运行动画和关卡导航 |
| `model.js` | 向量计算、连线检查、序章与 FFN 关卡 |
| `campaign.js` | 后续关卡和微型 Transformer 计算 |
| `engine-model.js` | 调度、存储、量化等教学成本模型 |
| `scene-art.js` | 3D 组件与矩阵视觉效果 |
| `module-cards.js` | 模块介绍卡片 |
| `transformer-demo.js` | 预先摆放接线、全部基础组件展开的原版模型演示 |
| `original-curriculum.js` | 原版算子、双语关卡、编码器—解码器计算与现代扩展分流 |
| `level-progress.js` | 本地进度与接线存档 |
| `i18n.js`、`locales/en.js` | 浏览器语言检测和中英文本 |
| `shell.js` | 开场入口与统一设置 |
| `music.js` | 原创合成背景音乐，无外部音频下载 |
| `vendor/` | Three.js 及其 MIT 许可证 |

## 部署

可放在 Nginx、GitHub Pages 或其他静态网站托管服务上。网页使用相对资源路径和 hash 关卡导航，支持部署到 `/games/neural-atelier/` 这样的子目录，无需配置应用路由回退。

网站运行需要根目录的 HTML、CSS、JavaScript 文件，以及 `locales/` 和 `vendor/`。不需要上传 `node_modules/`、测试、Git 数据或开发服务器。

也可以让 Web 服务器直接指向 Git 仓库目录，之后在该目录运行：

```sh
git pull --ff-only
```

拉取后刷新网页即可，不需要构建或重启服务。Web 服务器需要禁止访问隐藏路径（包括 `.git/`），并为 HTML、CSS、JavaScript 设置 `Cache-Control: no-cache`，让浏览器检查更新。服务器专用配置和凭证放在仓库外。

公开仓库也可以用 GitHub Pages 免费托管试玩页面：

1. 将源码推送到仓库的 `main` 分支。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
4. 等待部署完成，通过 Pages 显示的网址打开游戏，通常为 `https://chainhelen.github.io/neural-atelier/`。

项目包含 `.nojekyll`，不需要构建命令，也不需要在 GitHub 上运行 `npm run dev`。已有的 GitHub Actions 工作流负责测试；Pages 负责发布静态文件。

## 教学范围

小矩阵的投影、注意力和 FFN 执行真实的算术计算；ANE 调度和性能数字使用简化的教学模型。游戏不加载真实大模型，也不会调用苹果 ANE。设计参考 Kapitsa 的端侧推理思路，参考版本和模型假设见 [ENGINE_NOTES.md](ENGINE_NOTES.md)。
